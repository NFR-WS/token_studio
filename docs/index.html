Token Studio (SPA)

Single-page OIDC test client (Authorization Code + PKCE or implicit). Use this to test OIDC from GitHub Pages. Note: token endpoint CORS is required for code exchange in-browser.

Notes

  • Register the redirect URI in your IdP. For GitHub Pages the redirect URI is usually: https://<your-user>.github.io/token_studio/callback.html
  • Authorization Code + PKCE is recommended. The browser exchanges code for tokens — this requires the IdP token endpoint to allow CORS.
  • If the IdP does not allow CORS on the token endpoint use the implicit flow (tokens in fragment) or deploy the server app instead.
