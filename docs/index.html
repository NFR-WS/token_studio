Token Studio (SPA)

A lightweight OIDC test client for your Identity Provider. Designed for quick integration tests using Authorization Code + PKCE or implicit flows.

Notes

  • Register the redirect URI in your IdP: https://nfr-ws.github.io/token_studio/callback.html
  • The SPA exchanges code for tokens in-browser — your IdP token endpoint must allow CORS from GitHub Pages.
  • If the token endpoint blocks CORS use implicit flow or run the Flask server instead.
